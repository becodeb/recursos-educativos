deducida de X̄

Modelo simplificado del laboratorio: el tiempo de caída se aproxima con t = √(2h/g) y de allí se deduce v₀ = X̄ / (t·cos θ). El alcance teórico de referencia usa el tiempo de vuelo real T; el error relativo compara X̄ contra ese alcance. Para tiro horizontal (θ = 0°) ambos modelos coinciden.
